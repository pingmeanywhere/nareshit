==🟠**DML commands : (Data Manipulation Lang)**==
- `INSERT`
- `INSERT ALL`
- `UPDATE`
- `DELETE`
- `MERGE`

*1. All the DML commands acts on the table data (rows) only.*
*2. All the DML commands acts on the instance which is temporary memory.*
*3. To save the changes done by DML command execute `COMMIT` so the changes will reflect in the database also.*
*3. To cancel / undo the changes execute `ROLLBACK`*

==🔴**NOTE :** *ROLLBACK command will not work if commit command is executed after all the changes.*==

----

==🟠**INSERT Command**==
- *It is used to insert new rows in the table.*

==🟡*We can insert in three way :*==
- *Put the values in `VALUES()` in same order as the table create in the order.*
- *Specify the order first like `INSERT INTO emp(name, id) VALUES('name', 123)` so the value will be taken in the mentioned order.*
- *Use `&` character to take the value at runtime. For `DATE` and `CHARACTERS` use `'&column'` and for other just `&column` without any quotes.*

==🟡*Syntax*==
```sql
INSERT INTO table_name VALUES(val1, val2, val3...);
```

==🟠**INSERT ALL Command**==
- *It is used to insert multiple rows with only one command.*

==🟡*Synatx*==
```sql
INSERT ALL
    INTO table_name (column1, column2) VALUES (value1, value2)
    INTO table_name (column1, column2) VALUES (value3, value4)
SELECT * FROM dual;
```


==🟠**UPDATE Command**==
- *It is used to modify table data.*
- *We can use all the rows and also specific rows by using `WHERE` clause.*
- *We can update single column and also multiple column.*

==🟡*Syntax*==
```sql
UPDATE table_name
SET col1 = val1, col2 = val2 .....
[WHERE condition]
```


==🟠**DELETE Command**==
- *`DELETE` command is used to delete single or multiple rows from the table.*
- *We can delete all the rows without using the `WHERE` condition or single row with using the `WHERE` condition.*

```sql
DELETE FROM table_name [WHERE condition];
```


==🟠**FLASHBACK**==
- *Using the flashback we can see the data existed in the table at some point of time. Like I want to check what data existed 5 minutes ago in the table.*
- *By default we can flashback up ==900 secs== (15minus) only.*
- *It is useful to recover data after commit.*
- *Normal query returns the current data but `flashback` query returns the past data.*

==🟡*Syntax*==
```sql
SELECT * FROM table_name
AS OF TIMESTAMP (SYSDATE - INTERVAL - -);
```

*Q. Show me the emp table data 10 minutes before.*
```sql
SELECT * FROM emp
AS OF TIMESTAMP (SYSDATE - INTERVAL '5' MINUTE);
```

==🔵*Recovering data after commit*==

```sql
INSERT INTO emp 
SELECT * FROM emp 
AS OF TIMESTAMP (SYSDATE - INTERVAL '10' MINUTE);
```

==🔵*How to change undo retention period*==
- *The default undo retention period is 900 seconds.*
- *Execute the following command to change the retention period*

```sql
ALTER SYSTEM SET UNDO_RETENTION = 1800;
```
