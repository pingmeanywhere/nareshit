
==🟠**DDL Commands**==
- *`DDL` stands for data definition language.*
- *`DDL` command acts on table structure like `column`, `datatype` and `size`.*
- *All `DDL` commands are auto `commited`.*
```
DDL COMMAND = DDL COMMAND + COMMIT
```

==🔴**NOTE : *If you run `DDL` commands then all un-commited changes will saved to `DB` and can't be rollbacked using `ROLLBACK`.***==

==🟢**List of DDL commands**==
- CREATE
- ALTER
- DROP
- TRUNCATE
- RENAME
- FLASHBACK
- PURGE

==*1. CREATE*==
- *`CREATE` is used to create a brand new Table.*

*Syntax*
```sql
CREATE TABLE table_name (column_name datetype(size),...);
```

*Examples*
```sql
CREATE TABLE emp (id NUMBER(4), name VARCHAR2(15));
```

==*2. ALTER*==
- *This command is used to modify the table structure.*
- *Modifying the structure means `ADD` column, `DROP` column, `RENAME` a column, `MODIFY` a column (change data type or the size).*

==🟣ALTER **ADD**==

*Syntax*
```sql
ALTER TABLE table_name
ADD (col_name1 datatype(size), col_name2 datatype(size)--);
```

*Examples*
```sql
ALTER TABLE emp
ADD (gender VARCHAR2(6), dob DATE);
```

- *After adding the column, by default the new column are filled with null values. You can use `UPDATE` command to insert new values.*

==🟣ALTER  **DROP**==
*Syntax*
```sql
ALTER TABLE tabname DROP COLUMN  colname ;
```

*Examples*
```sql
ALTER TABLE emp
DROP COLUMN gender;
```
==🟣ALTER **RENAME**==
```sql
ALTER TABLE tabname RENAME COLUMN oldname TO newname ; 
```
