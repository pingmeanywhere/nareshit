==🟢`NUMBER(p)`==

- *Stores numbers with no decimal places.*
- *`p` (precision) specifies the maximum number of digits, up to 38.*

Example:

```
EMPID NUMBER(4)
```

- `10`, `100`, `1000` → Allowed
- `10000` → Not allowed

```sql
AADHARNO NUMBER(12)
PHONE    NUMBER(10)
ACCNO    NUMBER(11)
```

---

==🟢`NUMBER(p,s)`==

- Stores numbers with decimal places.
- `p` (Precision) → Total number of digits allowed.
- `s` (Scale) → Number of digits after the decimal point.

Example:

```sql
SALARY NUMBER(7,2)
```

- `5000` → Allowed
- `5000.55` → Allowed
- `50000.55` → Allowed
- `500000.55` → Not allowed
- `5000.5678` → Stored as `5000.57`
- `5000.5634` → Stored as `5000.56`
- `5000.5657` → Stored as `5000.57`

```
SAVG NUMBER(5,2)
```

- `78.56` → Allowed
- `100.00` → Allowed
- `1000.99` → Not allowed

==🔴Note: Oracle rounds numbers to the specified scale. Values exceeding the allowed precision after rounding cause an error.==
