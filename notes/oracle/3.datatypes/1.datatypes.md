Datatypes in Oracle

*Definition*

==🟡*A datatype specifies:*==

*1. Type of data allowed.*
*2. Amount of memory allocated.*

==🟡**Types of Datatypes**==

```
                    DATATYPES
                        |
      ┌─────────────────┼──────────────|──────────────┐
      |                 |              |              |
  CHARACTER          NUMERIC          DATE         BINARY
```

==🟢*1. Character Datatypes*==

|ASCII|Unicode|
|---|---|
|CHAR|NCHAR|
|VARCHAR2|NVARCHAR2|
|LONG|NCLOB|
|CLOB||

==🟢*2. Numeric Datatypes*==

- `NUMBER(p)`
    
- `NUMBER(p,s)`
    

==🟢*3. Date Datatypes*==

- `DATE`
    
- `TIMESTAMP`
    

==🟢*4. Binary Datatypes*==

- `BLOB`
    
- `BFILE`
