
==🟢***BFILE / BLOB***==
*Used to store multimedia data such as images, audio and videos.*

==🟡*`BFILE` (Binary File):*==
-  External LOB; the file is stored outside the database, and Oracle stores its location.
- Read-only access through Oracle.

==🟡*`BLOB` (Binary Large Object):*==
- Internal LOB; the binary data is stored inside the database.

==🟠Examples:==

```sql
PHOTO BLOB
SIGN  BFILE
```
