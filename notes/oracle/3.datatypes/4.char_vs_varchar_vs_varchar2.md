==🟡***Difference between `VARCHAR` and `VARCHAR2`***==

|`VARCHAR`|`VARCHAR2`|
|---|---|
|ANSI standard datatype name|Oracle-specific datatype|
|Currently behaves like `VARCHAR2` in Oracle|Stores variable-length character data|

==🟡***Difference between `CHAR` and `VARCHAR2`***==

| `CHAR`                              | `VARCHAR2`                             |
| ----------------------------------- | -------------------------------------- |
| Extra space is padded and reserved  | Unused space is not reserved           |
| Recommended for fixed-length fields | Recommended for variable-length fields |
| Example: `STATE_CODE CHAR(2)`       | Example: `STATE_NAME VARCHAR2(20)`     |
