==🟢***DATE***==

- *Stores both date and time.*
- *If the time is not specified, Oracle stores `12:00:00 AM`.*
- *Default date format is `DD-MON-YY` (depends on Oracle session settings).*
- *A `DATE` value occupies 7 bytes.*
- *Stores day, month, year, hour, minute and second.*
- Example:

```sql
DOB DATE
```

- `05-OCT-01` → `05-OCT-2001`
- `20-APR-98` → `20-APR-2098`
- `20-APR-1998` → `20-APR-1998`

==🟢***TIMESTAMP***==

- *Stores date, time and fractional seconds.*
- *Fractional seconds can be stored up to 9 digits.*
- *Storage size is usually 7 to 11 bytes, depending on fractional-second precision.*
- Example:

```sql
T TIMESTAMP
```

`08-AUG-2026 10:20:20.123`

- `08-AUG-2026` → Date
- `10:20:20` → Time
- `.123` → Fractional seconds
