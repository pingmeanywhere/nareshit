`VARCHAR2(size)`

- Stores variable-length character data up to 4000 bytes in standard SQL settings.
- Recommended for variable-length fields.
- Unused space is not wasted.

***Example:***

```sql
NAME VARCHAR2(10)
```

- `SACHIN` → 6 bytes used; remaining space is not reserved.
- `CHAR` and `VARCHAR2` store alphanumeric and special character data.

***Examples:***

```sql
PANNO    CHAR(10)
IFSC     CHAR(11)
EMAILID  VARCHAR2(20)
PWD      VARCHAR2(10)
```
