
==🟡**Changing Password in Oracle**==

==🟢**1. By User**==

*Both users and admins can change passwords.*

Connect as the user:

```
BATCH61/ORACLE
```

Execute the command:

```
PASSWORD
```

Example:

```
Changing password for BATCH61
Old password: ORACLE
New password: NARESH
Retype new password: NARESH
Password changed
```

==🟢**2. By Admin**==

Connect as admin:

```
SYSTEM/NARESH
```

Execute the command:

```
ALTER USER BATCH61 IDENTIFIED BY TIGER;
```

==🔴Note:==
- *User: Changes their own password using `PASSWORD`.*
- *Admin: Changes another user's password using `ALTER USER`.*
