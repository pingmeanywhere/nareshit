
**CLIENT / SERVER**

==🟢***1. Server***==

- Server is a system where Oracle is installed and running.
    
- Oracle manages two components inside the server:
    1. Database (DB)
    2. Instance
    
- DB is stored on the hard disk, and the instance uses RAM.
    
- DB is permanent storage, and the instance is temporary storage.
    
- The instance processes data and manages database operations. Changes are written to the database files as part of the save process.
    

==🟢***2. Client***==

- Client is a system from where users can:

1. Connect to the server.
2. Submit requests to the server.
3. Receive responses from the server. 

==🟣*Client Tools*==

- SQL*Plus
    
- SQL Developer
    

==🟡**Client–Server Architecture**==

```
USER ───── SQL*Plus ───── ORACLE ───── DATABASE

USER ── MySQL Workbench ── MySQL ───── DATABASE
```

**SQL (Structured Query Language)**

==🟣***1. Introduction***==

- SQL stands for Structured Query Language.
    
- SQL is used to communicate with Oracle and other relational databases.
    
- Users send commands called queries to perform database operations.
    
- A query is a command, instruction, or request given to the database.
    
- SQL is a non-procedural language.
    
- SQL was developed at IBM, initially under the name SEQUEL, later shortened to SQL.
    
- SQL is commonly used with relational databases.
    

==🟡*SQL Architecture*==

```
USER ── SQL*Plus ── SQL ── Oracle ── DATABASE

USER ── MySQL Workbench ── SQL ── MySQL ── DATABASE

USER ── pgAdmin ── SQL ── PostgreSQL ── DATABASE
```

==🟣***2. SQL Sublanguages***==

Based on database operations, SQL is categorized into five sublanguages.

| Sublanguage | Full Form                    | Commands                                                |
| ----------- | ---------------------------- | ------------------------------------------------------- |
| DDL         | Data Definition Language     | CREATE, ALTER, DROP, TRUNCATE, RENAME, FLASHBACK, PURGE |
| DML         | Data Manipulation Language   | INSERT, UPDATE, DELETE, MERGE, INSERT ALL               |
| DRL         | Data Retrieval Language      | SELECT                                                  |
| TCL         | Transaction Control Language | COMMIT, ROLLBACK, SAVEPOINT                             |
| DCL         | Data Control Language        | GRANT, REVOKE                                           |

==🟣***3. Data and Metadata***==
	
- Metadata: Structure or definition of data.
    
- Data: Actual values stored in the database.
    

Example:

|empid|ename|age|
|---|---|---|
|100|Sachin|40|

- `empid`, `ename`, `age` → Metadata (column definitions)
    
- `100`, `Sachin`, `40` → Data (actual values)

**SCHEMA**

==🔵***1. Introduction***==

- A schema is a collection of database objects owned by a database user.
    
- Objects created by a user are called schema objects.
    

**==🟡Schema Structure==**

```
SERVER
   |
DATABASE
   |
USER / SCHEMA
   |
TABLES, VIEWS, etc.
   |
DATA
```

==🔵***2. Oracle Users***==

Example: Oracle Free Database

```
SERVER
   |
ORACLE FREE
   |
   ├── SYS       (DBA)
   |
   └── SYSTEM    (DBA)
```

- SYS: Owns the data dictionary and has the highest-level administrative privileges.
- SYSTEM: An administrative account used for database management.

==🔴*Note: A user and a schema are closely related in Oracle. A schema contains the objects owned by that user.*==
