**ORACLE**
***1. Introduction***

- Oracle is an RDBMS software and also supports ORDBMS features.
- Oracle is used to create and manage databases.
- Using Oracle, users can store, read, update, and delete data.
- Oracle is used for DB Development and Administration.

***3. Oracle Versions***

Oracle Versions: 2, 3, 4, 5, 6, 7, 8i, 9i, 10g, 11g, 12c, 18c, 19c, 21c, 23ai, 26ai.

==🟡*Version Suffixes*==

- i → Internet
- g → Grid
- c → Cloud 
- ai → Artificial Intelligence

==🟡*Oracle Version History*==

*1. Before Version 8*

- Oracle mainly supported desktop-based applications.

2. Version 8i

- The suffix `i` was added to represent Internet.
    
- Oracle expanded its support for internet-based applications.
    

3. Version 10g

- The suffix `g` represents Grid.
    
- Grid computing uses multiple servers and resources to support database workloads and availability.
    

4. Version 12c

- The suffix `c` represents Cloud.
    
- Oracle databases can be deployed in two environments:
    1. On-Premises: Database runs on servers managed by the client.
    2. Cloud: Database runs on infrastructure managed by a cloud service provider.

5. Version 23ai and Later

- The suffix `ai` represents Artificial Intelligence.
- Oracle supports AI features, including vector data types and vector search for AI applications.
