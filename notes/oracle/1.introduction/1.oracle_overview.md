***ORACLE***

*`Data :` Data are raw facts that is facts about people, places and events.*
`Example:`
`100, Aquib, 40, Hyderabad`

*`Information :` Organized or processed data is called information. That means meaningful data are information.*
`Example:`

| empId | ename | age | city      |
| ----- | ----- | --- | --------- |
| 100   | Aquib | 23  | Hyderabad |
==🔵*Note: Here the data has some meaning like 23 is age of employee name Aquib.*==

*`Database :` A database is a organized collection of interrelated data.*
`Example: A bank db stores data related to customers,accounts,trans and loans etc and a another db stores data related to courses,faculty,students etc.`

**Types of Databases**
1. OLTP (online transaction processing db)
2. OLAP (online analytical processing db)

***1. OLTP (Online Transaction Processing)***
**Purpose:** Used to manage day-to-day business transactions.

`Examples:`
- Depositing or withdrawing money from a bank account
	
- Booking a ticket
    
- Placing an online order
    
- Updating customer details
    

**Characteristics:**

- Handles frequent transactions.
    
- Supports inserting, updating, deleting, and retrieving data.
    
- Requires fast responses and reliable transaction processing.
    

**Common database systems:**

- Oracle Database
    
- MySQL
    
- PostgreSQL
    
- Microsoft SQL Server
    

***2. OLAP (Online Analytical Processing)***
**Purpose:** Used to analyze large amounts of data to identify trends and support business decisions.

**Examples:**

- Analyzing monthly sales
    
- Comparing yearly profits
    
- Studying customer purchasing patterns
    
- Preparing business performance reports
    

**Characteristics:**

- Focuses on analysis and reporting.
- Often uses historical data from multiple sources.
- Supports complex queries and aggregations.

**Common database systems and platforms:**

- Oracle Database
- Microsoft SQL Server
- PostgreSQL
- Data warehouses and analytical platforms

---
***OLTP vs. OLAP***

| OLTP                                    | OLAP                                         |
| --------------------------------------- | -------------------------------------------- |
| Runs the business                       | Analyzes the business                        |
| Handles day-to-day transactions         | Supports analysis and reporting              |
| Primarily uses current operational data | Often uses historical and consolidated data  |
| Frequent inserts, updates, and deletes  | Frequent complex queries and aggregations    |
| Example: Recording a bank deposit       | Example: Analyzing monthly bank transactions |

**Remember:**

- **OLTP = Run the business**
- **OLAP = Analyze the business**
