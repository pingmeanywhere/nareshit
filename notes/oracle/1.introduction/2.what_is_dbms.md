***DBMS***

***Here are some important points about `dbms :`***
- *`DBMS` stands for database management system.*
- *It is software used to create and manage databases.*
- *Using `DBMS`, we can store, read, update, and delete data in a database.*
- *`DBMS` acts as an interface between the user and the database.*

*How interaction happens between a normal user and the database*
`USER  ──────────>  DBMS  ──────────>  DATABASE`

---

*Evolution of DBMS (Types of DBMS)*

| Year | Type   | Full Form              |
| ---- | ------ | ---------------------- |
| 1960 | FMS    | File Management System |
| 1970 | HDBMS  | Hierarchical DBMS      |
| 1970 | NDBMS  | Network DBMS           |
| 1980 | RDBMS  | Relational DBMS        |
| 1990 | ORDBMS | Object-Relational DBMS |
