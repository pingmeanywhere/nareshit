==🟠**Relational Operators (`=`,`>`,`<`, `<>`,`!=`)**==

- Equal to (`=`): Display employee details whose ID is `1003`.

```sql
SELECT * FROM emp WHERE id = 1003;
```

- Equal to (`=`): Display employee details whose name is `Vijay`.

```sql
SELECT * FROM emp WHERE name = 'Vijay Sen';
```

- Greater than (`>`): Display employees earning more than `10000`.

```sql
SELECT * FROM emp WHERE salary > 10000;
```

- Greater than (`>`): Display employees who joined after 2020.

```sql
SELECT * FROM emp WHERE hiredate > DATE '2020-12-31';
```

- Less than (`<`): Display employees who joined before 2020.

```sql
SELECT * FROM emp WHERE hiredate < DATE '2020-01-01';
```

- Not equal to (`<>`): Display employees not working in department `10`.

```sql
SELECT * FROM emp WHERE dept <> 10;
```

==🔴Note: Use `DATE 'YYYY-MM-DD'` to specify dates clearly in Oracle.==
