==🟠**ALIAS**==
- *Alias means another name.*
- *Alias is used to change the heading to improve the readability.*
- *Alias is created with the help of `AS` keyword.*

==🔴***NOTE: We can not use `alias name` in the `WHERE` clause as in the execution order `WHERE` clause executes first after then `SELECT`.***==

*Syntax*
```sql
SELECT column_name AS alias_name FROM table_name;
```

*Q1. Calculate the total salary paid to all employees.*

```sql
SELECT SUM(salary) AS total_salary FROM emp;
```


==🟠**USER_TABLES**==
- *It is a system table that stores information about tables created by user.*
- *These are : `USER_TABLES`, `TABLE_NAME`, `TABLESPACE_NAME`*

*Q1. Display list of tables created by user?*
```sql
SELECT TABLE_NAME FROM USER_TABLES;
```

*Q2. List of tables name starts with "E"  ?*
```sql
SELECT TABLE_NAME FROM USER_TABLES WHERE TABLE_NAME LIKE 'E%';
```

==🟠**ALL_USERS**==
- *It is a system table that stores information about users created in oracle db.*
- *These are : `ALL_USERS` ,`USERNAME`, `CREATED`*

*Q1. List of users created in oracle db ?*
```sql
SELECT USERNAME FROM ALL_USERS;
```

*Q2. Display on which date user `test` is created ?*
```sql
SELECT CREATED FROM ALL_USERS WHERE USERNAME='TEST';
```
