==🟠**IN Operator**==

- *Use_ `_IN_` _operator for list comparison.*
- *Use_ `_IN_` _operator for_ `_=_` _comparison with multiple values.*
- *We can avoid long chaining of_ `_column = 'A' OR column = 'B'_` _and use_ `_IN_` _instead.*
- *List => 10, 20, 30, 40*

==*Syntax*==

```sql
SELECT * FROM <table_name>
WHERE <colname> IN (val1, val2, val3...);
```

_Q1. Select employees whose department is_ `_10_`_,_ `_20_` _or_ `_30_`_._

```sql
SELECT * FROM emp
WHERE dept IN (10, 20, 30);
```

_Q2. Select employees whose names are 'Arman Khan', 'Priya Sharma' and 'Amit Kumar'._

```sql
SELECT * FROM emp
WHERE name IN ('Arman Khan', 'Priya Sharma', 'Amit Kumar');
```

_Q3. Select employees who belong to Hyderabad, Delhi or Mumbai._

```sql
SELECT * FROM emp
WHERE city IN ('Hyderabad', 'Delhi', 'Mumbai');
```

**BETWEEN Operator**

- _Use_ `_BETWEEN_` _operator for range comparison._
- _We can avoid_ `_column >= 30000 AND column <= 50000_` _and use_ `_BETWEEN_` _instead._
- _Range => 30000 to 50000_

==*Syntax*==

```sql
SELECT * FROM <table_name>
WHERE column BETWEEN val1 AND val2;
```

_Q1. Select all employees whose salary is between 30000 and 50000._

```sql
SELECT * FROM emp
WHERE salary BETWEEN 30000 AND 50000;
```

_Q2. Select all employees whose salary is between 50000 and 30000._

```sql
SELECT * FROM emp
WHERE salary BETWEEN 50000 AND 30000;
```

_OUTPUT: NO rows selected here_

==🟡***OTE: BETWEEN operator works from `lower` to `upper` bound only and includes both boundary values.***==

_Q3. Select employees who joined between 01-JAN-2022 and 31-DEC-2024._

```sql
SELECT * FROM emp
WHERE hiredate BETWEEN DATE '2022-01-01' AND DATE '2024-12-31';
```

==**LIKE Operator**==

- _Use_ `_LIKE_` _operator for pattern comparison._
- _Patterns may contain alphabets, digits and special characters that match using wildcard characters._
- _Wildcard Characters:_
    - `_%_` _: Matches 0 or more characters._
    - `___` _: Matches exactly 1 character._

==*Syntax*==

```sql
SELECT * FROM <table_name>
WHERE <column> LIKE '<some_pattern>';
```

_Q1. Select employees whose names start with A._

```sql
SELECT * FROM emp
WHERE name LIKE 'A%';
```

_Q2. Select employees whose names end with 'Khan'._

```sql
SELECT * FROM emp
WHERE name LIKE '%Khan';
```

_Q3. Select employees whose names contain 'an'._

```sql
SELECT * FROM emp
WHERE name LIKE '%an%';
```

_Q4. Select employees whose names have exactly 10 characters._

```sql
SELECT * FROM emp
WHERE name LIKE '__________';
```

_Q5. Select employees whose names start with 'A' and have exactly 5 characters._

```sql
SELECT * FROM emp
WHERE name LIKE 'A____';
```

_Q6. Select employees whose cities start with 'M'._

```sql
SELECT * FROM emp
WHERE city LIKE 'M%';
```

==🔴***NOTE:***==

- `_LIKE 'A%'_` _— Matches names starting with A._
- `_LIKE '%A'_` _— Matches names ending with A._
- `_LIKE '%A%'_` _— Matches names containing A anywhere._
- `_LIKE '_____'_` _— Matches values containing exactly 5 characters._
- _Oracle_ `_LIKE_` _is case-sensitive by default. Use_ `_UPPER()_` _or_ `_LOWER()_` _for case-insensitive matching._
