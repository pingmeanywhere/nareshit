==🟠**Arithmetic operators**==

*Q. Display employee salary after adding `_2000_`.*

```sql
SELECT name, salary, salary + 2000 AS new_sal
FROM emp;
```

*Q. Display employee salary after deducting `_1000_`.*

```sql
SELECT name, salary, salary - 1000 AS new_sal
FROM emp;
```

*Q. Display annual salary of each employee.*

```sql
SELECT name, salary, salary * 12 AS annual_sal
FROM emp;
```

*Q. Display half of each employee's salary.*

```sql
SELECT name, salary, salary / 2 AS half_sal
FROM emp;
```

*Q. Display employees whose salary after adding_ `_2000_` _is greater than_ `_15000_`.*

```sql
SELECT *
FROM emp
WHERE salary + 2000 > 15000;
```
