==🟠**IS Operator**==
- *`IS` operator is used for `NULL` value comparision.*
- *We can use `IS` with comparing the specific column.*

==🟡*Syntax*==
```sql
SELECT * FROM <table_name>
WHERE <column> IS NULL;
```

```sql
SELECT * FROM <table_name>
WHERE <column> IS NOT NULL;
```

*Q1. Select all employees whose commission is NULL.*

```sql
SELECT * FROM emp
WHERE comm IS NULL;
```

*Q2. Select employees who receive a commission.*

```sql
SELECT * FROM emp
WHERE comm IS NOT NULL;
```
