==🟠**Displaying Data Using `SELECT`**==

- The `SELECT` command is used to display data from a table.
- We can display all rows and columns or specific rows and columns.

==🟢***Syntax***==

```sql
SELECT column1, column2, ...
FROM table_name;
```

==🟢***SQL Query Structure***==

- `SQL` = English
- `Queries` = Sentences
- `Clauses` = Words
- `FROM` clause → Specifies the table from which to retrieve data.
- `SELECT` clause → Specifies the columns to display.

==🟣***Examples***==

Display employee names and salaries:

```sql
SELECT ename, sal
FROM emp;
```

Display employee names, jobs and hire dates:

```sql
SELECT ename, job, hiredate
FROM emp;
```

Display all columns and rows from the `emp` table:

```sql
SELECT *
FROM emp;
```

- `*` represents all columns.

==🟠**`WHERE` Clause**==

- The `WHERE` clause is used to filter rows based on a condition.
- It helps display only the rows that match the condition.

==🟢***Syntax***==

```sql
SELECT column1, column2, ...
FROM table_name
WHERE condition;
```

==🟢***Condition***==

- A condition is a relational expression that evaluates to `TRUE` or `FALSE`.
- It uses relational operators such as `>`, `>=`, `<`, `<=`, `=`, `<>` and `!=`.
- If the condition is `TRUE`, the row is selected. Otherwise, it is not selected.

==🟣***Example***==

Display employee details whose `empid` is `103`:

```sql
SELECT *
FROM emp
WHERE empid = 103;
```
