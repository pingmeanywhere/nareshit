
==🔴*Note: `LONG` is a legacy datatype. Prefer `CLOB` for large character data.*==

`LONG`

- Stores character data up to 2 GB.
- Example:

```
MOVIE_REVIEW LONG
```

`CLOB` (Character Large Object)

- Stores large amounts of character data.
- Example:

```
TEXT CLOB
```

`NCHAR` / `NVARCHAR2` / `NCLOB`

- `N` stands for National character set.
- Supports Unicode characters from different languages.
- Character storage depends on the character set used.

Example:

```
NAME VARCHAR2(20)   -- Uses the database character set
NAME NVARCHAR2(20)  -- Uses the national character set
```

- `SACHIN` contains 6 characters. Its storage size depends on the character set.
- `NCHAR` is fixed-length, `NVARCHAR2` is variable-length, and `NCLOB` stores large amounts of national character data.
