**Creating User in Database**

==🟢***Step 1: Connect as DBA***==

Connect to Oracle using the DBA account.

```
Username : SYSTEM
Password : NARESH
```

==🟢***Step 2: Create a New User***==

`Syntax:`

```
CREATE USER <name> IDENTIFIED BY <pwd>
DEFAULT TABLESPACE USERS
QUOTA UNLIMITED ON USERS;
```

==🔴Note: In Oracle 12c and later, common users generally require the prefix `C##`. To create a user without this prefix in a suitable test environment, execute the following command before creating the user.==

```
ALTER SESSION SET "_ORACLE_SCRIPT" = TRUE;
```

`Example:`

```
CREATE USER BATCH61 IDENTIFIED BY ORACLE
DEFAULT TABLESPACE USERS
QUOTA UNLIMITED ON USERS;
```

==🟢***Step 3: Grant Permissions to the User***==

```
GRANT CONNECT, RESOURCE TO BATCH61;
```

Permissions:

- CONNECT — Allows the user to connect to the database.
- RESOURCE — Provides privileges to create certain database objects.
- DBA — Provides extensive database administrative privileges.

==🔴Note: `"_ORACLE_SCRIPT"` is an internal parameter. Use it only in suitable practice environments; for normal administration, follow Oracle's recommended user-creation method.==
