==🟠**Creating Tables in Database**==

==🟢***Syntax***==

```sql
CREATE TABLE table_name
(
    column_name datatype(size),
    column_name datatype(size)
);
```

==🟢***Rules***==

1. Table and column names should start with an alphabet (for simple identifiers).
2. Names should not contain spaces or special characters, except `_`, `$`, and `#`.
3. Maximum identifier length is 128 bytes in Oracle 12.2 and later.
4. A table can have up to 1000 columns.
5. The number of rows is not fixed; it depends on available storage and other limits.

==🟢***Examples of Identifiers***==

- `123EMP` → Invalid
- `EMP 123` → Invalid
- `EMP*123` → Invalid
- `EMP_123` → Valid

==🟢***Example: Creating an `EMP` Table***==

| Column     | Datatype       |
| ---------- | -------------- |
| `EMPID`    | `NUMBER(4)`    |
| `ENAME`    | `VARCHAR2(10)` |
| `JOB`      | `VARCHAR2(10)` |
| `SAL`      | `NUMBER(7,2)`  |
| `HIREDATE` | `DATE`         |
| `AGE`      | `NUMBER(2)`    |
| `DEPT`     | `VARCHAR2(10)` |

```sql
CREATE TABLE emp
(
    empid    NUMBER(4),
    ename    VARCHAR2(10),
    job      VARCHAR2(10),
    sal      NUMBER(7,2),
    hiredate DATE,
    age      NUMBER(2),
    dept     VARCHAR2(10)
);
```

- *The above command creates the table structure (metadata), which includes column names and their datatypes.*

==🟡***`DESC` (DESCRIBE)***==

- Used to display the structure of a table.

==🟢***Syntax***==

```sql
DESC table_name;
```

==🟢***Example***==

```sql
DESC emp;
```

==🟢***Output:***==

```
Name       Null?    Type
---------- -------- ------------
EMPID               NUMBER(4)
ENAME               VARCHAR2(10)
JOB                 VARCHAR2(10)
SAL                 NUMBER(7,2)
HIREDATE             DATE
AGE                 NUMBER(2)
DEPT                VARCHAR2(10)
```

==🟠**Inserting Data into a Table**==

- The `INSERT` command is used to insert data into a table.
- We can insert:
    1. Single row
    2. Multiple rows

Inserting a Single Row

==🟢***Syntax***==

```sql
INSERT INTO table_name
VALUES (value1, value2, value3, ...);
```

==🟢***Examples***==

```sql
INSERT INTO emp
VALUES (100, 'sachin', 'clerk', 4000, '10-AUG-26', 40, 'hr');
```

We can also specify column names in any order.

```sql
INSERT INTO emp (empid, ename, age, hiredate, job, sal, dept)
VALUES (101, 'arvind', 25, SYSDATE, 'analyst', 9000, 'sales');
```

==🟢***Inserting Multiple Rows***==

==🟢***Syntax and Example***==

```sql
INSERT ALL
    INTO emp VALUES (102, 'david', 'manager', 8000, DATE '2020-10-10', 35, 'sales')
    INTO emp VALUES (103, 'vijay', 'analyst', 12000, DATE '2018-04-05', 38, 'it')
SELECT 1 FROM dual;
```

==🟢***Entering Values at Runtime***==

- Use `&` variables to accept values at runtime in SQL*Plus*.

Example

```sql
INSERT INTO emp
VALUES (&empid, '&ename', '&job', &sal, '&hiredate', &age, '&dept');
```

- Enter the values when prompted. Character and date values are enclosed in single quotes.
- To execute the previous command again, use `/`.

==🟡***Inserting `NULL` Values***==

- `NULL` represents a missing or unknown value.
- It is not equal to `0`, a space, or an empty string.
- `NULL` values can be inserted in two ways.

==🟢***Method 1: Specify `NULL`***==

```
INSERT INTO emp
VALUES (106, 'ajay', NULL, NULL, DATE '2019-01-12', 23, 'sales');
```

==🔴*Note: In Oracle, an empty string (`''`) is treated as `NULL` for character data.*==

==🟢***Method 2: Omit Column Names***==

```
INSERT INTO emp (empid, ename, hiredate, age, dept)
VALUES (107, 'vijay', SYSDATE, 32, 'hr');
```

- The omitted columns `job` and `sal` receive `NULL`, provided they have no default value and allow `NULL`.

==🟢***Saving Data Using `COMMIT`***==

- `INSERT` changes are part of the current transaction and are not permanent until committed.
- Use `COMMIT` to save the changes.

```sql
COMMIT;
```

- After `COMMIT`, the changes are permanent and visible to other transactions.
